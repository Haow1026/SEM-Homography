# SEM 图像拼接工具 (SEM Image Stitching Tool)

Mac 桌面应用，用于拼接扫描电子显微镜 (SEM) 图像。纯平移对齐（2 DOF），支持 3×3 网格、蛇形扫描与自动匹配。输入为位深一致的 8 位或 16 位灰度图像。

A Mac desktop app for stitching Scanning Electron Microscope (SEM) images. Pure translation alignment (2 DOF), supports 3×3 grids, serpentine scans, and arbitrary topologies.

---

## 功能特性  Features

- **纯平移对齐**：SEM stage 仅做 XY 移动，不做旋转和缩放；保留浮点位移到最终合成
- **混合对齐策略**：边缘图 SIFT（抗划痕）+ 相位相关（亚像素精细对齐）
- **任务内特征缓存**：每张图的边缘图与 SIFT 特征只计算一次；匹配结束即释放缓存，失败或取消也会清理
- **稳健全局平差**：过滤小角落重叠；发生冲突时逐条试算，仅在找到唯一可恢复一致性的单边排除方案时剔除该匹配，保留全部图像连通
- **网格/蛇形扫描模式**：已知网格时仅匹配上下左右直接邻居，避免对角线误匹配
- **亚像素羽化融合**：按到图像边缘的距离加权，统一归一化，减少黑边、重影及多图交汇接缝；结果不依赖叠加顺序
- **大图分块融合**：默认以 1024×1024 像素块累加，减少大尺寸全景的浮点工作内存；块边界沿用原图权重与插值邻域
- **16 位 TIFF**：特征提取使用 8 位工作副本，原始位深保留到融合和导出；预览归一化不影响导出数据
- **原分辨率接缝检查**：支持 100%、缩放拖动、红青叠加、A/B 交替显示及已排除匹配标记
- **多语言界面**：简体中文 / English / 日本語

## 使用  Usage

### GUI 模式（推荐）

```bash
python3 gui.py
```

1. 点击 **选择图片文件**，多选要拼接的 TIFF 图像
2. 在 **文件与布局** 核对采集顺序；默认按自然文件名排序（如 2 在 10 之前），可选中文件后上移/下移、倒序或恢复排序
3. 若已知扫描布局，打开 **使用已知网格**，输入行数、列数，并按实际采集方式设置 **蛇形扫描**、**首行从右向左**
4. 核对编号布局：上方是首行，数字对应文件列表编号；不启用网格时使用自动匹配
5. 点击 **开始拼接** 后自动切换至日志页；成功后预览结果，再点击 **导出全景图** 保存

界面区分准备就绪、拼接中、正在取消、已取消、失败、成功。开始新任务或修改文件/布局都会清除旧结果并禁用导出，
只有当前任务成功后才能导出。行列值无效、网格尺寸与文件数量不符时不能启动。
重新加载的图片数量若与上一批不同，且不适用于当前网格，会自动切回自动匹配并在布局区提示；
如需网格约束，请重新设置行列数。图片数量相同或已预先设好匹配的网格时保留扫描设置。

点击 **取消** 后会等待当前步骤结束，再停止后续计算；取消期间不能启动另一任务，也不会导出部分结果。
单次 OpenCV 图像读取、SIFT、FFT、求解或重采样调用不能从中间强行打断，因此大图取消可能需要等待当前调用完成。
关闭窗口也会请求取消，后台线程不会在窗口销毁后操作控件。

### 接缝检查

拼接成功后点击 **接缝检查 / 原分辨率**。默认显示全景，可用 **100%**、加减按钮、鼠标滚轮缩放，拖动平移。
100% 表示一个图像像素对应一个画布像素；窗口只对当前视野取样，支持超过 32767 像素宽的全景。

在下拉菜单选择匹配对后，按最终全局坐标显示两张原图的重叠区，默认以 100% 红青叠加查看：
A 放在红通道，B 放在青通道；亮度一致且对齐的区域呈灰色，错位或亮度差可能产生彩边。
也可单独查看 A、B，或选择 **交替显示 A/B**。16 位源图使用两图共同的显示范围；检查操作不会修改拼接像素或导出结果。

菜单会标记已排除匹配，详情显示文件名、内点数、全局残差及测量/最终位移；全景中的红色连线表示被排除的匹配。
编号与主窗口的采集文件列表一致，包括蛇形及首行从右向左的情况。

源图按需在后台重读，每次只加载所选的两张。若文件丢失，或大小/修改时间与拼接时不同，会提示重新拼接。
选择新文件、启动新任务或关闭主窗口会关闭检查窗口，避免混用不同批次。

### 性能基准

缓存不改变特征参数和对齐模型。描述子占用额外内存，匹配结束后、融合开始前释放；原图不长期留在检查报告中。
可用下面的脚本在独立进程中比较缓存开关，记录阶段耗时、提取次数、输出哈希和进程峰值 RSS：

```bash
python3 tools/benchmark_cache.py --output benchmarks/local.json
# 对实际图像测量（报告不包含输入文件路径）
python3 tools/benchmark_cache.py --repeats 3 --output benchmarks/sem-local.json image1.tif image2.tif image3.tif
```

默认合成九图缓存基准的历史三轮结果见 [benchmarks/README.md](benchmarks/README.md)：特征提取 72 → 9 次，
本机总耗时中位数 12.29 → 4.75 秒（约 2.58 倍），输出哈希一致；进程峰值 RSS 中位数约 127.2 → 148.2 MiB。
这组数值在分块融合之前测得。
测量使用单个 OpenCV 线程和独立进程，合成结果不代表真实 SEM 图像的耗时或对齐精度。Windows 暂不采集峰值 RSS。
Python API 可传入 `use_feature_cache=False` 做对照；GUI 默认启用缓存。

默认分块融合只改变计算顺序与工作缓冲区，不改变配准参数、距离权重、原位深或亚像素插值。
两张浮点累加缓冲区合计最多 16 MiB，此外仍有块内重采样临时数组；全部源图和最终 8/16 位全景仍需在内存中。
因此这一步降低融合开销，尚不等于支持超出内存容量的全流程拼接。融合期间可在图块之间取消，不会发布部分全景。

可单独比较旧版全画布融合与新版分块融合，记录峰值 RSS、耗时和输出哈希：

```bash
python3 tools/benchmark_blending.py --output benchmarks/local-blending.json
```

九张 2048×2048 图像、4098×4098 全景的三轮合成基准中，8/16 位进程峰值 RSS 中位数
约 775/843 → 191/244 MiB，下降 75%/71%，输出哈希一致。该基准仅测融合，不包含匹配、界面或导出；
详细数据与限制见 [benchmarks/README.md](benchmarks/README.md)。

### 命令行模式

```bash
python3 main.py image1.tif image2.tif image3.tif ...
```

传入要拼接的 TIFF 文件路径（至少 2 张，均为同一位深的灰度图），输出项目目录下的 `stitched_panorama.tif`。16 位输入输出仍为 16 位；GUI 导出 16 位结果时请选择 TIFF 或 PNG。

对于已知的 3×3 蛇形扫描，请按采集顺序传入图像并启用网格模式。例如采集顺序为
第一行从左到右、第二行从右到左、第三行从左到右时：

```bash
python3 main.py --grid 3x3 --serpentine \
  F82H-BA07-057_003.tif F82H-BA07-057_004.tif F82H-BA07-057_005.tif \
  F82H-BA07-057_006.tif F82H-BA07-057_007.tif F82H-BA07-057_008.tif \
  F82H-BA07-057_009.tif F82H-BA07-057_010.tif F82H-BA07-057_011.tif
```

网格模式只匹配上下左右邻居；默认自动模式也会过滤“仅角落相交”的小重叠匹配。
GUI、命令行与 Python API 均支持网格配置；GUI 还可预览采集顺序和左右起始方向。

- `--min-axis-overlap 0.70`：默认要求至少一个方向的重叠比例达到 70%。斜向扫描或不规则布局可按实际情况调低；两个方向仍必须有正重叠。
- `--residual-threshold 10`：全局匹配边残差阈值（像素）。超限时尝试逐条排除单个匹配，并重新求解其余约束；只有唯一方案能让所有图像保持连通、全部保留边均满足原阈值时才恢复。若无可行方案或有多个方案，则报错并指出相关图像对。

一条误匹配可能把残差分摊到多条正确匹配上，因此不再一次删除所有超限边，也不会仅凭内点数量选择要保留的边。
恢复日志会列出被排除图像对、测量位移、其余约束预测的位移，以及恢复后的最大残差。

### 精度与数据说明

相位相关在原始灰度重叠区上计算，校正整数裁剪产生的坐标差后，将精细位移真正传入全局平差。
每张图只在最终合成时做一次双线性重采样；整数位置无需重采样。亚像素对齐会改变采样值，
羽化融合也会平均重叠区，输出不应被视为原始测量像素的逐点拷贝。软件不做自动曝光补偿。

弱纹理、周期重复结构、漂移、旋转或曝光差异仍可能造成误配或可见接缝；已知扫描布局时优先指定网格。
匹配图必须连通。算法只处理平移，不能修正扫描畸变。当前回归验证使用合成数据，实际 SEM 数据仍需检查对齐效果。

## 算法流程  Algorithm

```
图像加载 → SIFT + 相位精对齐 → 几何筛选 → 全局平差 → 亚像素羽化融合
                │                    │
           ┌────┴────┐          ┌────┴────┐
      边缘图 SIFT    重叠几何筛选  残差剔除   网格邻接
      (抗划痕)    (拒绝角落匹配)  (异常边)  (可选)
```

| 阶段 | 算法 | 图像 | 目的 |
|------|------|------|------|
| 粗对齐 | SIFT + FLANN + RANSAC | 边缘图 (GaussianBlur + Sobel) | 抑制细小划痕，匹配宏观结构 |
| 精细对齐 | 相位相关 (Phase Correlation) | 原始灰度重叠区 | 校正粗位移，保留亚像素偏移 |
| 全局定位 | 加权最小二乘 + 残差剔除 | 可靠匹配边 + 中心锚定 | 抑制错误边，保持闭环约束 |
| 融合 | 距边权重 + 亚像素重采样 | 原位深图像 | 减少接缝，避免零权重黑边 |
